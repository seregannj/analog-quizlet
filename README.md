# analog-quizlet · Лексио

**Тренажёр иностранных слов** с интервальными повторениями (алгоритм SM-2, как в Anki).

Работает офлайн, без аккаунтов и серверов. Чистый Vanilla JS — **ноль зависимостей**.

---

## 🎯 Возможности

| | |
|---|---|
| 📥 **Массовый импорт** | `слово - перевод - пример` списком, хоть 999 строк |
| 🧠 **Интервальные повторения** | SM-2: 1 день → 3 дня → 7 дней → 3 недели |
| 🎯 **3 режима урока** | выбор варианта · карточки (Забыл/Трудно/Знал/Легко) · примеры-пропуски |
| 📚 **Словари** | сколько угодно, 12 языков |
| 📊 **Прогресс** | серия дней, точность, проблемные слова |
| 💾 **Резервные копии ZIP** | своя реализация, без библиотек |
| 🌓 **Темы** | светлая / тёмная / системная |
| 🔊 **Озвучка** | Web Speech API |
| ⌨️ **Горячие клавиши** | `1`–`4` выбор и оценка карточек, `Enter`/`Пробел` — проверить/продолжить |
| 📱 **Адаптив** | мобильный + десктоп |

---

## 📥 Формат импорта

По одному слову на строку. Разделитель — любой из: `-`, `—`, таб (из Excel), `|`, `=`, `:`, два пробела.
**Пробелы вокруг дефиса не обязательны** — `apple-яблоко` тоже работает.

```
apple - яблоко - I eat an apple every day
house - дом
beautiful - красивый
mother-in-law - свекровь
1. wonderful - чудесный
```

Нумерация `1.` и маркеры списка игнорируются. Дефисы внутри слова (`mother-in-law`)
не ломают разбор, если основной разделитель выделен пробелами.

## 🚀 Запуск

Просто откройте `index.html` в браузере — сборка, npm и зависимости не нужны.

```bash
git clone https://github.com/seregannj/analog-quizlet.git
cd analog-quizlet
python -m http.server 8080   # или просто откройте index.html
```

---

## 📦 Сборка в Android-приложение

Репозиторий готов для обёртки через [web-to-app](https://github.com/shiaho777/web-to-app):

- точка входа — `index.html`
- классические `<script>` (не ES-модули) — работает даже с `file://`
- пути относительные, сборка происходит из корня
- внешних зависимостей нет, интернет не требуется

## 🗂 Структура

```
index.html                 точка входа
styles/
  base.css                 переменные, темы, каркас, адаптив
  components.css           кнопки, плитки, карточки, графики
src/
  main.js                  инициализация, toast/модал/фидбек
  core/
    icons.js               24 inline-SVG иконки (без эмодзи)

    sm2.js                 алгоритм интервальных повторений

    router.js              hash-роутинг

    onboarding.js          приветственный экран
    home.js                главная
    decks.js               словари
    words.js               слова + импорт
    train.js               урок (3 режима)
    stats.js               прогресс
    settings.js            темы + ZIP-бэкап
```

## 💾 Где хранятся данные

`localStorage` браузера, ключ `lexio_v1`. Никаких серверов.

> ⚠️ Чистка истории браузера удалит прогресс — делайте резервную копию (Настройки → «Резервная копия»). Если данные когда-нибудь повредятся, автоматически сохранится копия в ключе `lexio_v1_corrupt`.
